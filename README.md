# AI CCTV System

AI CCTV Dashboard using Python, Flask, OpenCV and YOLOv8.

## Features

- Real-time camera monitoring
- AI human detection
- Object detection using YOLOv8
- Dashboard website
- Telegram alert notification

## Technologies Used

- Python
- Flask
- OpenCV
- Ultralytics YOLOv8
- Telegram Bot API
- GitHub

## How It Works

The system captures video from a camera and uses YOLOv8 to detect objects in real time.  
When a person is detected, the system can send an alert notification through Telegram.  
The dashboard website displays the camera view and detection information.

## Project Purpose

This project was developed as a smart security system prototype.  
It can be used for home monitoring, room security, and portfolio presentation.
